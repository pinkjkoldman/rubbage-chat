# RubbageChat 用户界面重设计（产品经理视角）

## 1. 产品定位与目标用户

定位：面向中小团队、专业人士和企业的桌面即时通讯工具。蓝色品牌色传达
信任、可靠与专业感；核心承诺是「清晰、高效、安全」。

目标用户：

- 日常靠 IM 协作的办公人员：要求快速找到会话、快速回复；
- 管理多个联系人的用户：需要清晰的列表层级、搜索与未读管理；
- 注重隐私与通知控制的高级用户：可配置在线状态、免打扰、主题。

核心使用场景（按频次）：

1. 打开应用 → 3 秒内进入最近会话；
2. 在会话内快速回复、引用、回应；
3. 查找历史联系人/会话并继续聊天；
4. 处理好友申请与通讯录维护；
5. 调整通知、主题与账号设置。

## 2. 设计原则

1. **会话优先**：会话列表是主页，未读、置顶、草稿、时间一目了然；
2. **搜索直达**：`Ctrl+K` 全局聚焦搜索，会话/联系人统一过滤；
3. **状态透明**：连接状态、在线状态、送达/已读状态随时可见；
4. **操作就近**：常用操作（回复、回应）悬停在消息旁即出现，不打断阅读；
5. **空状态即引导**：任何空页面都给出下一步动作；
6. **克制一致**：统一的圆角、间距、颜色令牌与反馈动效。

## 3. 信息架构

```text
┌────────────────────────────────────────────────────────┐
│ 导航（左侧胶囊栏）   │ 主面板（336px）      │ 内容区        │
│ 消息 ●未读          │ 标题 + 添加按钮      │ 聊天 / 联系人   │
│ 联系人              │ 搜索框 (Ctrl+K)     │ / 请求 / 设置  │
│ 通知 ●待处理         │ 会话 / 联系人列表    │               │
│ 设置                │ 用户条（头像/账号/菜单）│              │
└────────────────────────────────────────────────────────┘
```

- 主面板承载列表与搜索；内容区承载与列表项对应的详情页；
- 用户相关操作集中在底部用户条（个人资料、切换账号、退出）；
- 通知页只做「好友申请」处理，未读数用导航角标提示。

## 4. 页面规范

### 4.1 会话列表（主面板，消息页）

- 列表项：头像 + 名称（含置顶徽章）+ 时间 + 摘要（草稿优先）+ 未读徽章；
- 置顶会话以「置顶」胶囊标识，区别于普通会话；
- 未读数量以品牌色徽章显示，免打扰会话降级为灰色；
- 空状态：引导文案 + 「添加好友」入口；
- 搜索无结果：给出「清除搜索」操作。

### 4.2 聊天页

- 头部：对方头像、名称、在线状态；右侧「搜索记录 / 更多」；
- 消息气泡：左右分栏、日期分栏、回复卡片、表情回应徽章、送达/已读状态；
- **悬停快捷操作**：气泡上方浮出「↪ 回复」「👍 回应」，满足 80% 高频操作；
- 右键菜单保留完整操作（复制/回复/回应/编辑/撤回/下载）；
- 输入区：回复/编辑预览条 + 附件 + 表情 + 发送；
- 空会话：品牌图形 + 引导按钮「添加好友，开始聊天」。

### 4.3 联系人 / 通知页

- 联系人列表展示昵称、账号、签名与在线状态；
- 通知页聚合待处理申请，支持接受/拒绝；
- 空状态分别引导「添加好友」与「暂无新请求」。

### 4.4 设置页

- 左侧分类（外观/聊天/通知/隐私/账号），右侧内容卡片；
- 账号区提供个人资料编辑、切换账号与退出登录；
- 外观区提供主题、紧凑模式与在线状态开关。

## 5. 交互与反馈

- 导航与列表切换有 180ms 淡入 + 位移动效；
- 消息进场 180-220ms 淡入上浮；
- 所有可点元素悬停变色、按下缩放，符合桌面端习惯；
- 主题切换即时生效，浅色/深色两套令牌全覆盖。

## 7. 后续迭代建议

1. 会话列表分组（置顶/最近），未读置顶排序；
2. 消息流「未读分隔线」与「新消息」提示条；
3. 群聊与消息免打扰快捷切换（会话内开关）；
4. 端到端加密标识与安全提示；
5. 多语言（EN/中文）与无障碍（键盘导航、对比度）。
