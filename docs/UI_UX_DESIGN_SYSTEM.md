# RubbageChat 界面设计系统（UI/UX）

> 承接产品定位（专业、可靠的办公即时通讯），把视觉语言与交互行为
> 固化为可复用规范。实现位于 `apps/client/ui/Main.qml` 的令牌与组件。

## 1. 色彩令牌

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `bg` | `#F6F5F3` | `#0F1115` | 页面底色 |
| `panel` | `#FFFFFF` | `#171A20` | 面板/卡片 |
| `panelAlt` | `#F0EEEB` | `#1F232C` | 次级面板/悬停底 |
| `line` | `#E4E1DC` | `#2C313D` | 分隔线/描边 |
| `textMain` | `#1C1F26` | `#F6F7F9` | 主文本 |
| `textMuted` | `#6D7280` | `#98A0AF` | 次要文本 |
| `accentSurface` | `#2563EB` | `#2563EB` | 品牌主色（按钮/气泡） |
| `accentGlow` | `#4F8DFF` | `#4F8DFF` | 品牌渐变终点 |
| `accentSoft` | `#E7EFFE` | `#1B2A4D` | 选中态柔光底 |
| `good` | `#2FBF71` | `#2FBF71` | 在线/成功 |
| `danger` | `#EF4444` | `#EF4444` | 错误/撤回 |

对比度约束：正文 ≥ 7:1，次要文本 ≥ 4.5:1，白字配品牌蓝 ≥ 4.5:1。

## 2. 圆角与间距

- 圆角阶梯：控件 14 / 卡片 20 / 面板 24；
- 间距阶梯：4 / 8 / 16 / 24 / 32 / 40；
- 列表项内边距 12-16，卡片内容边距 24；
- 导航胶囊宽 88，主面板宽 336。

## 3. 字体层级

| 场景 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 24 | Bold |
| 面板标题 | 20-22 | Bold |
| 会话/联系人名称 | 14 | Bold |
| 正文/消息 | 14 | Normal |
| 摘要/状态 | 12 | Normal |
| 时间戳/角标 | 10-11 | Normal |

## 4. 动效规范

- 进场：180-220ms 淡入 + 上浮 6px，`OutCubic`；
- 状态切换（颜色/边框）：160-180ms 颜色渐变；
- 按压反馈：按钮缩放 0.975，120ms；
- 悬停反馈：气泡轻微放大（1.008）+ 阴影加深，颜色 160ms；
- 窗口切换：180-200ms 淡入位移，禁止弹跳与拖尾。

## 5. 组件状态

每个交互组件必须具备四种状态：

| 状态 | 规则 |
|---|---|
| 默认 | 面板色 + 1px 描边 |
| 悬停 | `panelAlt` 或品牌色加深 |
| 按下 | 缩放 0.975，颜色加深一级 |
| 焦点 | 2px 品牌色焦点环（外扩 3px），键盘可达 |
| 禁用 | 不透明度 0.45，无悬停反馈 |

## 6. 无障碍

- 键盘：`Tab` 顺序从左到右，`Ctrl+K` 聚焦搜索，`Enter` 发送；
- 焦点可见：所有可交互组件显示焦点环；
- 语义色不单独作为信息载体（错误同时用图标/文案）；
- 目标尺寸 ≥ 32×32，列表项 ≥ 44 高。

## 7. 组件清单（已落地）

- 按钮：`PrimaryButton`（渐变品牌色）、`GhostButton`（描边）——均带焦点环；
- 输入：`AppTextField`（焦点环 + 可选搜索图标）、`AppSwitch`、`AppComboBox`；
- 列表：会话/联系人项（悬停变色、选中柔光、置顶徽章、未读角标）；
- 消息：气泡（渐变/描边、尾巴、日期分栏胶囊、回应徽章、悬停快捷操作）；
- 滚动条：6px 细条、圆角、按需显示；
- 反馈：`toast` 顶部滑入、空状态引导按钮。
